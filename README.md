# tarto_talk
A dedicated tarot RAG bot for Telegram. Ask questions about tarot cards in plain language — the bot retrieves relevant passages from a curated 78-card corpus and synthesizes answers using local models.

Features:

• Thematic search ("what cards deal with completion")
• Card lookup ("tell me about Death")
• Random draw ("give me a card")
• Simple 6-card spread (past/present/future)

Built with: local embedding + reranking + generation models, Chroma vector store, Telegram interface.
